# Planet Pawsitive

A recycling application developed as part of the Singapore Institute of Technology's GAM200 project.

Planet Pawsitive aims to encourage recycling through a virtual pet concept inspired by Tamagotchi-style interactions.

## Project Overview

The project explores how gamification can encourage users to recycle beverage containers. Users can interact with a virtual pet while engaging with recycling activities.

## My Role

## My Contributions

- Set up a Jenkins Continuous Integration (CI) pipeline from scratch.
- Automated daily builds and dependency rebuilding across Linux, Android and Web platforms.
- Integrated Jenkins with GitHub pull requests to run automated checks before code is merged.
